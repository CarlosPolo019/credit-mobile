# Shared

## Purpose
- Infraestructura y UI reutilizable sin logica de dominio pesada.

## Key Files -> Role
- `api/`: Axios e interceptores.
- `config/`: backend URL.
- `lib/`: storage.
- `ui/`: componentes visuales.

## External Deps
- Axios, Keychain, React Native.

## Risks / TODOs
- No introducir dependencias de pages/features en shared.
