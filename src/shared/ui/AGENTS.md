# Shared UI

## Purpose
- Componentes visuales reutilizables y consistentes.

## Key Files -> Role
- `Screen.jsx`: wrapper de pantalla.
- `Button.jsx`: accion primaria/secundaria.
- `TextField.jsx`: input.
- `Banner.jsx`: mensajes de estado.
- `theme.js`: tokens visuales.

## External Deps
- React Native components.

## Risks / TODOs
- Evitar estilos inline repetidos fuera de componentes base.
- Mantener textos legibles en pantallas pequenas.
