# Docs

Documentacion de planificacion y reglas tecnicas para `credit-mobile`.

El cliente mobile usa TypeScript y NativeWind, con `challenge-blossom` como referencia visual local.

## Indice
- `planning-guidelines.md`: formato de planes tecnicos.
- `permissions-rules.md`: permisos Android permitidos.

## Regla
