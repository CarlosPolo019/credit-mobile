# Planning Guidelines

## Estructura
```text
docs/<feature-name>/
├── requirements.md
└── technical-plan.md
```

## `requirements.md`
Debe incluir:
- objetivo;
- alcance;
- requisitos funcionales;
- requisitos no funcionales;
- criterios de aceptacion;
- riesgos.

## `technical-plan.md`
Debe incluir:
- stack y dependencias;
- arquitectura;
- archivos a modificar;
- pasos de implementacion;
- decisiones tecnicas;
- validacion.

## Regla
No implementar features grandes sin dejar plan aprobado o actualizado.
